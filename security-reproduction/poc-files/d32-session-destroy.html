D-32: Deriv Session Destruction PoC

This page demonstrates how an attacker can destroy a victim's Deriv SmartTrader session by embedding front-channel.html in a cross-origin iframe.

Status: Initializing...

Attack Mechanism

The front-channel.html page on dsmarttrader.deriv.com checks if it's same-origin with its parent. When loaded cross-origin, the check throws an error, triggering localStorage/sessionStorage cleanup.

// From dsmarttrader.deriv.com/front-channel
try {
    let isSameOrigin = top.location.hostname === self.location.hostname;
} catch (err) {
    localStorage.removeItem("client.accounts");       // Auth tokens
    sessionStorage.removeItem("active_loginid");       // Active session
    localStorage.removeItem("active_loginid");         // Active session
    sessionStorage.removeItem("_elevaddon-6app");      // Support widget
    sessionStorage.removeItem("_elevaddon-6create");   // Support widget
    localStorage.removeItem("ws_cache");               // WebSocket cache
}

Result: If the victim was logged into SmartTrader, their session data has been wiped. They will be logged out on next page load.

Impact

  • Any website can embed this iframe to forcibly log out Deriv SmartTrader users
  • No user interaction required beyond visiting the attacker's page
  • Destroys authentication tokens (client.accounts) and active session (active_loginid)
  • Can be combined with phishing: destroy session → redirect to fake login page
